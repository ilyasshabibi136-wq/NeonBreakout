NEON BREAKOUT - Android project

This project wraps the supplied standalone Neon Breakout HTML game in an Android WebView.

Open the folder in Android Studio.
Then:
1. Let Gradle sync.
2. Test with Run.
3. For Google Play: Build > Generate Signed Bundle / APK > Android App Bundle.
4. Choose release and create/select a signing key.
5. The resulting .aab is the file uploaded to Google Play Console.

Package: com.neonbreakout.app
Version: 1.0 (code 1)
Minimum Android: 6.0 (API 23)
